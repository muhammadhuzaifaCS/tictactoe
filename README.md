# tictactoe

Terminal tic-tac-toe against a computer opponent. See `problem.md` for the problem and
requirements, and `spec.md` for the current round's exact behavior.

## Run

```
python tictactoe.py
```

## Test

```
python -m unittest
```

(Tests cover board/game logic directly — win/draw detection, move validation, and the
computer's move strategy — not the interactive input loop.)
